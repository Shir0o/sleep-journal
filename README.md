# Sleep Journal

A Flutter mobile application for tracking and analyzing sleep patterns, daily habits, and restorative health metrics.

## Features

- **Daily Sleep Logging:** Record bed times, wake times, sleep latency, and sleep quality.
- **Analytics & Trends:** Visualize sleep duration, consistency, and correlation with daytime habits.
- **Third-Party Sync:** Integrations for syncing health data (Fitbit, Google Drive backup).
- **Privacy First:** Local-first storage with optional encrypted cloud backup.

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install) (3.x or later)
- Android Studio / Xcode for simulator or device runs

### Installation

```bash
# Clone the repository
git clone https://github.com/Shir0o/sleep-journal.git
cd sleep-journal

# Install dependencies
flutter pub get

# Run the app
flutter run
```

## Running Tests

```bash
flutter test
```
